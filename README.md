📊 Flikshop iConsultancy – Data Modeling & BI Project
📌 Overview

This project focused on designing a scalable data infrastructure and analytics framework for Flikshop’s Admin Dashboard (Admin Panel V2). The goal was to transform unstructured product requirements into a normalized database and enable meaningful business intelligence reporting.

🎯 Objectives
Translate UI/UX designs into structured data requirements
Design a normalized database (1NF → 3NF) for scalability
Define key business metrics (KPIs) for performance tracking
Enable future dashboarding and analytics capabilities
🛠️ Tools & Technologies
SQL (MySQL / PostgreSQL) – Data modeling & schema design
MySQL Workbench / pgAdmin – ER diagrams & database visualization
Figma – Admin dashboard UI reference
Excel / Documentation Tools – Data mapping & planning
📊 Key Contributions
🔹 Data Modeling & Architecture
Designed a fully normalized relational database (1NF → 3NF)
Built Entity Relationship Diagrams (ERDs) and SQL schemas
Structured data to support scalability and future backend integration
🔹 KPI Development & Analytics

Defined and structured key business metrics, including:

Postcards sent (weekly/monthly)
Delivery success rate
Processing time (order → delivery)
Credit purchases & usage
Repeat user rate
🔹 UI → Data Mapping
Translated Figma Admin Panel designs into backend data structures
Mapped dashboard components (tags, recipients, gift cards, etc.) to database tables
Ensured alignment between product design and data architecture
🔹 Data Integrity & System Design
Established relationships, constraints, and validation logic
Created sample datasets to support analytics and reporting
Designed schema to support future BI dashboards
📈 Outcome & Impact
Built a scalable data foundation for Flikshop’s admin platform
Enabled structured tracking of product and operational performance
Improved readiness for business intelligence dashboards and reporting
🚀 Future Enhancements
Integrate with Power BI / Tableau for real-time dashboards
Implement ETL pipelines for automated data ingestion
Expand schema to support user behavior analytics
